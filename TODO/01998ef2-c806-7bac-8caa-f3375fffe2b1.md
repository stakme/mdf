# New Subcommand: Update

## What I need

- Backlog tickets may have `status` and `updated_at` fields. I want to update them after a ticket is completed, but currently, I have to do it manually.
- It will be useful to update multiple tickets at once.

## So I will create...

### `update` subcommand

```bash
markdfm update --fm "status=done" --fm updated_at <file_path> <file_path> ...
```

- `--fm` flag can be used multiple times
- Default value will be used if new value is not provided in the flag.
