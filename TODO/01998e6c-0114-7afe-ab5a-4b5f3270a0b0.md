# .local config

## What I need

- I want to add a .local config file to override default config
- For example, I want to override the default value of `author` field with my name, @stakme

## So I will create...

### .config/markdfm.mts

```ts
import { defineConfig, z } from "markdfm/config";

export default defineConfig({
    schema: z.object({
        title: z.string(),
        created_at: z.iso.datetime().default(() => new Date().toISOString()),
        author: z.string(),
    })
})
```

### .config/markdfm.local.mts

```ts
import { defineConfig } from "markdfm/config";

export default defineConfig({
    schema: z.object({
        author: z.string().default("@stakme"),
    })
})
```

When I run `markdfm new --fm title="New Note" ./directory`, it should create a new file with the default values from both configs.

created_at: 2025-09-28T03:44:26.918Z
