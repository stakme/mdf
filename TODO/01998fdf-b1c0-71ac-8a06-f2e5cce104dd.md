### `mdf list` subcommand

```bash
% node dist/cli.mjs list --vpath backlog/virtual --filter "status=todo" ./TODO 
└── backlog
    └── virtual-paths
        └── Foobar title here (./TODO/01998fae-2708-7f9f-823b-0db6e7dc0c53.md)
```

- `--vpath` flag is optional. If not specified, it will list all files in the directory. If specified, it will list only files with matching prefix.
- `--filter` flag is optional. If not specified, it will list all files. If specified, it will list only files matching the filter.
