# Implement viewer command again!

## What I need

Simple web server that renders Markdown files.

## So I will create...

### `viewer` command

A new `viewer` command that implements a simple web server that renders Markdown
files. Use hono, marked, tailwindcss and shadcn/ui. No custom styling.

- This command supports any schema and directory.
- Use `vpath` to organize files in the virtual path tree.
- Support `--filter` and `--vpath` options.

```bash
npx @stakme/mdf viewer --filter "status=todo" ./TODO
```

- Index page shows all files in the virtual path tree.
- Follow the design pattern in documentation sites.
