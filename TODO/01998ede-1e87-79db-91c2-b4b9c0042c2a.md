# Reserved params for path/name for query format

## What I need

- `query` command works but it cannot show the path of the note. I need to show the path of the note in the output to handle these notes in shell scripts.

```
% node dist/cli.mjs query --filter "status: done" --format "[{{status}}] # {{title}} 
({{tags}})" ./TODO 
[done] # TODO ()
[done] # New Feature: fm flags for array fields like tags ()
[done] # New Subcommand: validate and fix ()
[done] # .local config ()
[done] # No Newline after frontmatter ()
```

## So I will create...

### `query` command

```bash
% node dist/cli.mjs query --filter "status: done" --format "{{relpath}} {{f.status}} {{f.title}} ({{f.tags}})" ./TODO

TODO/01998ede-1e87-79db-91c2-b4b9c0042c2a.md done # New Feature: fm flags for array fields like tags ()
TODO/01998edf-1f1f-7f1b-b0a1-04898479aa63.md done # New Subcommand: validate and fix ()
```

`query` command should support `relpath`, `abspath` and `filename` params in the format string.
