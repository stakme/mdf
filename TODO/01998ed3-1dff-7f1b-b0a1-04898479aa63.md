# Schema definition per directory

## What I need

- I want to define a schema per directory: backlog tickets and bug reports should have different schemas.

## So I will create...

### `mdf.mts` in each directory

```ts
import { defineConfig, z } from "@stakme/mdf/config";

export default defineConfig({
    schema: [
        {
            name: "backlog",
            glob: "backlog/**",
            schema: z.object({
                title: z.string(),
                status: z.enum(["todo", "in_progress", "done"]).default("todo"),
                author: z.string(),
                tags: z.array(z.string()).default(() => []),
                created_at: z.iso.datetime().default(() => new Date().toISOString()),
            }),
        },
    ],
    defaultSchema: "backlog",
});
```

Users should be able to define multiple schemas in a single `mdf.mts` file.
If no schema is specified, the default schema should be used.

`schema` can be an object or an array of objects. If it is an object, it is equivalent to an array with a single element that is the default schema.
