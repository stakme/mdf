# New Feature: Tags

## What I need

- I want to add tags to my notes to filter them

## So I will create...

### .config/markdfm.mts

```ts
import { defineConfig, z } from "@stakme/markdfm/config";

export default defineConfig({
	schema: z.object({
		title: z.string(),
		created_at: z.iso.datetime().default(() => new Date().toISOString()),
		tags: z.array(z.string()).default(() => []),
	}),
});
```

### `new` command

It will be easy and useful to create a new file with a specific front matter.

Such as:

```sh
markdfm new --fm title="New Note" --fm tags=["tag1","tag2"] ./directory
```

or

```sh
markdfm new --fm title="New Note" --fm tags=tag1 --fm tags=tag2 ./directory
```

I feel the latter is more convenient but both are acceptable.
