# Sort an output of `list` with timestamp

## What I need

I want an output of `list` command to be sorted by timestamp. The newer
documents should be listed first. This is a common requirement for blog
applications.

## So I will create...

### .config/mdf.mts

```ts
import { defineConfig, z } from "@stakme/mdf/config";

export default defineConfig({
    schema: {
        docs: {
            glob: "docs/**",
            schema: z.object({
                title: z.string().min(1),
            }),
            sort: (a, b) => a.title.localeCompare(b.title),
        },
        default: {
            glob: "**",
            schema: z.object({
                title: z.string(),
                created_at: z.iso.datetime().default(() =>
                    new Date().toISOString()
                ),
            }),
            sort: (a, b) => a.created_at.localeCompare(b.created_at),
        },
    },
});
```

- System uses `sort` option to sort documents.

### `list` command

- Sort an output of `list` using `sort` option in the config file.
- If `sort` option is not defined, system uses file paths to sort documents.

### `viewer` command

- Sort documents in the viewer using `sort` option in the config file.
- If `sort` option is not defined, system uses their titles to sort documents.
