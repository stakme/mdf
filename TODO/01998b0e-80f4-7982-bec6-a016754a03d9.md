### .config/markdfm.mts

```ts
import { defineConfig, z } from "markdfm/config"

export default defineConfig({
    schema: z.object({
        title: z.string(),
        created_at: z.iso.datetime(),
    })
})
```

### `new` command

Specify a directory to create new files
```
markdfm new ./directory
```

It will be useful to create a new file with a specific front matter. 
Schema of front matter will be defined by users, so this command should accept any schema.
(In this case, `created_at` will be set to current time if not specified. So useful!)

```sh
markdfm new --fm title="New Note" --fm created_at="2025-09-27" ./directory 
```
