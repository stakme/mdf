# Enhance output of list command

## What I need

Currently, I get a list of files like this

```bash
% node dist/cli.mjs list --filter "status=todo" ./TODO
├── Prepare for v1.0.0 release (./TODO/01K6D4R6DARC0GA9WCD0V6PCWY.md)
└── Enhance output of list command (./TODO/01K6M1342CF0W3D6VN8KB49789.md)
```

I makes sence but I feel it is bit curious that `├──` occurs in the output
without any context.

## So I will create...

### list command

We will update the list command to show the directory name as a prefix.

```bash
% node dist/cli.mjs list --filter "status=todo" ./TODO
./TODO
├── Prepare for v1.0.0 release (./TODO/01K6D4R6DARC0GA9WCD0V6PCWY.md)
└── Enhance output of list command (./TODO/01K6M1342CF0W3D6VN8KB49789.md)
```

Remind that we will keep accessible paths to the files like
`./TODO/01K6D4R6DARC0GA9WCD0V6PCWY.md`. For example, it should not be like this:

```bash
./TODO
├── Prepare for v1.0.0 release (01K6D4R6DARC0GA9WCD0V6PCWY.md)
```
