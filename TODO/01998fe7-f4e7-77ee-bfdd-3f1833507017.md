# Refactor and merge `markdfm list` and `markdfm query`

## What I need

- We have two commands: `markdfm list` and `markdfm query`. They are similar but different, this is confusing.

## So I will create...

- I want to merge them into one command, `markdfm list`.
- `markdfm list` should have a `--filter` flag to enable filter mode. Filter offer four modes: exact match `=`, loose match `~=`, prefix match `^=` and suffix match `$=`.
- `markdfm list` should have a `--vpath` flag to enable virtual path mode. `vpath` always uses prefix match mode.
- `markdfm list` should have a `--format` flag to enable format mode. If none format is specified, it should use the current style to show files with vpath structure.

## Done

- Merged the former `list` and `query` behaviors under `markdfm list` with shared filter handling and output modes.
- Added support for advanced filter operators (`=`, `~=`, `^=`, `$=`) and kept `--vpath` as a prefix filter.
- Enabled optional `--format` templates while preserving the virtual path tree when no template is provided.
