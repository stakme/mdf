# CI/CD for npm package

## What I need

- Deploy to npm when a new version is published. It will be nice if I can deploy
  with version tag.
- Run tests in GitHub Actions before deploying.

## So I will create...

### .github/workflows/publish.yml

Workflow file for GitHub Actions. This name will be registered in npmjs.com for
OIDC authentication.

### Local deployment

At first, I will create a local deployment script that will run tests and deploy
to npm when a new version is published.

### GitHub Actions workflow

Create a GitHub Actions workflow that will run tests and deploy to npm when a
new version is published.

## Outcome

- Added `scripts/publish.mjs` to run tests and publish locally with optional
  dist-tags or dry runs.
- Added `.github/workflows/publish.yml` release workflow that installs
  dependencies, runs checks and tests, and publishes with provenance (prerelease
  tags publish under `next`).
