# New Subcommand: validate and fix 

## What I need

- I want to update our schema and refactor our structure
- In this case, I want to update existing files to comply with the new schema
- I want to validate existing files to ensure they comply with the new schema

## So I will create...

### .config/mdf.mts

```ts
import { defineConfig, z } from "@stakme/mdf/config";

export default defineConfig({
    schema: z.object({
        title: z.string(),
        description: z.string(), // <- new field
        created_at: z.iso.datetime(),
    })
})
```

### `validate` command

```sh
mdf validate ./directory
```

This command will validate existing files to ensure they comply with the new schema. 

The output should be a list of files that do not comply with the new schema. Exit with code 1 if there are any files that do not comply with the new schema.

```sh
./directory/01998e00-424c-7996-b61b-2590d9e7cdd4.md: description field is missing
```

### `fix` command

```sh
mdf fix --fm description="TODO: Add description here" ./directory
```

This command will update existing files to comply with the new schema.
Files that do not comply with the new schema will be updated with given default values. Please note this value is not a default value of zod schema.
