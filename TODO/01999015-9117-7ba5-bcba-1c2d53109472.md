# Command Aliases like npm run

## What I need

I would not like to repeal long commands like `node dist/cli.mjs new --fm vpath=backlog/new-feature ./TODO` but I would like to create aliases for them.

## So I will create...

### .config/markdfm.local.mts

```typescript
export default defineConfig({
    aliases: {
        todo: `list --filter "status=todo" ./TODO`
    },
});
```

### `markdfm run` subcommand

```bash
markdfm run todo
```

It should execute the command in the config file and run as if I typed `markdfm list --filter "status=todo" ./TODO` in the terminal.
