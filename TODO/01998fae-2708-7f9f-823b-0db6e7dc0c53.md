# Reserved params for structure: `vpath`

## What I need

- I want to express and organize my backlog tickets in a directory-like structure, but I don't want to create actual directories. Directory approach makes it impossible to move files to a different directory without breaking the structure and to refresh contents without deleting physical files.
- I want to use virtual paths to express the structure of my backlog tickets.

## So I will create...

### `vpath` param


```markdown
---
vpath: backlog/foobar
---
```

I will define a virtual path param that will be used to express the structure of my backlog tickets.


### .config/markdfm.mts

```ts
import { defineConfig, z } from "markdfm/config";

export default defineConfig({
    schema: z.object({
        title: z.string(),
        vpath: z.string().default(""),
        status: z.enum(["todo", "in_progress", "done"]).default("todo"),
        author: z.string(),
        tags: z.array(z.string()).default(() => []),
        created_at: z.iso.datetime().default(() => new Date().toISOString()),
        updated_at: z.iso.datetime().default(() => new Date().toISOString()),
    }),
    virtualPath: {
        param: "vpath",
        separator: "/",
    },
});
```
