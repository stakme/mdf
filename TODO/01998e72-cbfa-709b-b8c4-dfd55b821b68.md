# New Subcommand: query

## What I need

- I want to query my notes using a simple language
- Because we already have utilities like grep and ack, I don't want to reinvent the wheel. What I want is a simple language to query my notes over the frontmatter.

## So I will create...

### `query` command

```sh
markdfm query --filter "status: todo" --filter "tags: 'new feature'" --format '[status: {{status}}] {{title}} ({{tags:, }})'
```

This command will output:

```
[status: todo] New Note (new feature, refactoring)
[status: todo] Next Note (new feature)
```
