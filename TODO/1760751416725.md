# Reduce complexity of list command

## What I need

The `--filter` option provides a way to filter documents by virtual path.

```bash
% node dist/cli.mjs list --filter 'vpath ~= recipe' ./docs  
./docs
└── recipes
    ├── Flat Structure (./docs/flat-structure.md)
    ├── Backlog Tickets (./docs/backlog-tickets.md)
    ├── Batch retagging (./docs/recipe-batch-retagging.md)
    └── Local configuration (./docs/local-conf.md)
```

So, we don't need to use `--vpath` option anymore.

```
% node dist/cli.mjs list --help                             
Usage: mdf list [options] <directory>

List Markdown files using virtual paths

Arguments:
  directory                  Directory containing Markdown files to list

Options:
  --vpath <prefix>           Filter entries by virtual path prefix
  -f, --filter <expression>  Filter expression supporting =, ~=, ^=, $= operators (default: [])
  --format <template>        Output template using {{field}} placeholders
  -q, --quiet                Print only document IDs
  --strict                   Treat invalid Markdown files as errors
  -h, --help                 display help for command
```

## So I will create...

### commands using virtual paths options

- Remove `--vpath` option
- Enhance text of `--filter` option and provide description of four operators

### docs

- Update docs to remove `--vpath` option
